1.docker란 정확히 무엇인가?
    1-1. Docker 컨테이너는 격리된 실행환경이며, 그 안에서 하나의 메인 프로세스(PID 1)를 중심으로 동작하는 공간입니다.
    1-2. 컨테이너는 다음을 포함합니다.
        => 파일 시스템, 프로세스 공간, 네트워크 공간, 사용자 정보, 환경 변수, 필요한 라이브러리 등.. 
    
    1-3. 컨테이너를 실행하면 Docker는 지정한 명령어를 실행합니다.
        => Docker run nginx -> PID 1은 nginx가 됩니다.
        => Dokcer run ubuntu bash -> PID 1은 bash가 됩니다.
        => 이러한 메인 프로세스가 종료되면 컨테이너도 종료됩니다.
    
    1-4. 메인 프로세스가 다른 프로세스를 실행할 수 도 있습니다.
        => 우분투 PID 1 bash에서 python, gcc, vim 여러 자식 프로세스를 만들 수 있습니다.


2. 프로세스란 무엇인가?
    2-1. 프로그램 : 디스크에 저장된 실행 파일
    2-2. 프로세스 : 프로그램이 메모리에 올라와 실제로 실행되고 있는 프로그램
        => 운영체제는 메모리에 올려서 실행하고 이 떄 프로세스 하나가 생성됩니다.
    2-3. 프로세스는 단순히 코드만 있는게 아닙니다.
        => 실행 중인 코드
        => 현재 실행 위치 (어디까지 실행했는지)
        => 사용하는 메모리
        => 열린 파일
        => 네트워크 연결
        => 환경 변수
        => OS는 이런 정보를 관리하면 CPU를 할당합니다.

3. 운영체제는 모든 프로세스에게 번호를 붙입니다.
    3-1. PID는 process ID입니다.


4. 대부분의 프로세스는 다른 프로세스가 생성합니다.
    4-1. python app.py를 bash에서 실행하면 bash는 부모 프로세스, python 자식 프로세스입니다.

5. 메인 프로세스란?
    5-1. 실행 환경에서 가장 중심이 되는 프로세스입니다.
    5-2. docker에서 PID 1인 프로세스를 메인 프로세스라고 합니다.
    5-3. docker는 PID 1이 살아있는 동안만 실행 상태로 유지합니다.
